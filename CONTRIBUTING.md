# Contributing to CopyThat

Thanks for helping the library grow.

## Add a prompt
The easiest way: use **Submit a prompt** on the website. Include the model you wrote it for and, if you can, the result it made. Every submission is tested before it goes live, credited to you.

## Improve the site
1. Fork the repo and create a branch.
2. `npm install`, add `.env.local` (see README), `npm run dev`.
3. Keep the design language: dark, calm, one accent colour, real content (no lorem ipsum), accessible (labels, focus states, reduced motion).
4. Open a pull request describing what changed and why.

By contributing you agree your code is released under MIT and your prompt content under CC BY 4.0.
